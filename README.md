## 📊 대시보드 핵심 수치

2026-11-09 로컬 앱에서 **전체 필터**로 화면에 표시된 값:

| 지표 | 결과 |
|---|---:|
| 분석 주문 수 | **96,203건** |
| 매출 합계 | **R$ 15.37M** |
| 평균 주문 금액 | **약 R$ 160** |
| 배송 기간 중앙값 | **10.2일** |
| 배송 지연율 | **8.1%** |
| 평균 리뷰 점수 | **4.16점** |

앱이 표시한 분석 인사이트: 제때 도착한 주문의 평균 리뷰 **4.30점**, 늦게 도착한 주문의 평균 리뷰 **2.57점**(차이 **1.73점**). 집단 차이는 관찰된 상관관계이며 인과관계라고 단정할 수 없다.

분석용 주문 데이터는 배송 완료 건 중 구매 시각이 2017-01-05 이상, 2018-08-30 미만인 주문을 중심으로 생성한다.

## 🏪 판매자 유형과 위험 관리

판매자 유형 화면에서는 주문 건수·판매액·평균 리뷰·마지막 판매 후 경과일·첫 판매 후 경과일을 입력하고, **핵심 우량 / 신규 성장 / 휴면 / 저평점 위험** 중 하나의 결과를 확인한다.

이탈 위험 화면은 판매자별 예측 위험과 점검 우선순위를 표시한다. 여기서 **이탈은 실제 폐업이 아니라 학습용 주문 중단 정의**다. 결과를 실제 사업자 평가·제재 판단에 사용해서는 안 된다.

## 💬 RAG — 근거부터 확인하고 답하기

```text
질문 → 임베딩 검색 → 근거 문서 추출 → GPT 답변 → 인용한 근거 ID 검증
```

- **채널 A**: 사실표 (`olist_facts.csv`)
- **채널 B**: 사실표 + 모델 설명서 (`olist_model_guide.md`)
- **채널 C**: 사실표 + 모델 설명서 + 실습용 규정집 (`olist_seller_policy.pdf`)
- 생성된 답변에 실제로 검색하지 않은 근거 ID가 포함됐는지 검사한다.

> 규정집은 실습용 근거로 취급하며 공식 Olist 약관·소비자 권리로 오인하지 않는다. OpenAI API 호출 비용이 발생할 수 있다.

## ▶️ 로컬 실행 (Windows 11, VS Code)

```powershell
cd C:\workspace_2\olist-dashboard-app
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 열면 된다. RAG를 사용하려면 `OPENAI_API_KEY` 환경변수, Streamlit Secrets 또는 화면의 비밀번호 입력 칸으로 키를 제공한다. **키는 코드나 GitHub에 넣지 않는다.**

기존 로컬 학습 환경은 Python 3.12.10이었으며 저장된 `.pkl` 모델과 `scikit-learn` 버전 호환성이 필요하다.
